# Refined character masters

Seven editable Blender component masters, derived from the retained S-07, mech-enemy and native legacy-enemy sources. All textures needed by each Blender file are packed. Original masters are not overwritten.

The separate `textures/` PNGs are the edited material maps used to regenerate the portable GLBs. Keep them with the source files. Geometry export deliberately retains the established gameplay bindings; Godot compilation carries forward the original native skeleton, node hierarchy and animation libraries.

See [the art review and rebuild instructions](../../docs/godot-port/character-refinement.md), [comparison gallery](../../docs/godot-port/character-refinement.html), and `tools/art/character_refinement/build.ps1`.
