# Nomad receiver refinement

Original Blender receiver for the native Godot game. The frozen browser artwork is unchanged. It retains the existing upper-deck site and scanner lifecycle while placing the controls toward the main aisle.

- `NomadReceiver.blend`: 208 editable mesh parts, original packed PBR textures, independent scanner cartridge/contacts/progress/lamp and studio setup.
- `NomadReceiverRecovered.blend`: the complete assembly with the existing earned archive and seed instruments, cleaned and oriented toward the same aisle.
- `receiver-front.png`, `receiver-rear.png`, `receiver-recovered.png`: source renders.
- `manifest.json`: runtime geometry inventory, position and bounds.
- `source-fit.json`: component contacts, original walking footprint, neighbouring machine and earned-hardware clearance.
- `reward-cleanup.json`: face counts and total surface area removed from the two original attachment meshes.
- `gltf-validation.json`: Khronos validation for both exports.

The main receiver exports to 15 batches / 45,524 triangles. Two original 512-pixel PBR sets provide restrained enamel wear and oxidised metal. It has anchored flanges, connected column/tray supports, a sealed case, machined controls, guarded handles, screened rear ventilation and fully terminated antenna/power routes. The empty module bay has separate exposed contacts. Runtime text reports actual state; it is not baked into a display texture or generated by a separate viewport.

The original archive/seed meshes are retained in a small separate GLB. Cleaning removes 668 collapsed faces and microscopic slivers below 0.000000001 square metres, totaling approximately 0.00000001334 square metres out of 4.4425 square metres in source coordinates. Lossless vertex import prevents fine retained faces collapsing again. This is geometry hygiene, not an altered reward or a new model design.

[Rohde & Schwarz's EB500 brochure](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/dl_common_library/dl_brochures_and_datasheets/pdf_1/EB500_bro_en_5214-3800-12_v0500.pdf) was consulted for a compact monitoring receiver's front controls, display and antenna/service connections. The game model, textures and lettering are original; no manufacturer geometry, image or branding is included.

Rebuild from the repository root:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --python-exit-code 1 --python tools/art/native_machine/build_receiver.py
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --python-exit-code 1 --python tools/art/native_machine/clean_receiver_rewards.py
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --python-exit-code 1 --python tools/art/native_machine/verify_receiver.py
node tools/art/native_machine/validate_receiver.mjs
& test-results/godot-tools/Godot_v4.7.2-stable_win64_console.exe --headless --path godot --editor --import
& test-results/godot-tools/Godot_v4.7.2-stable_win64_console.exe --headless --path godot --script res://tools/bake_machine.gd
& test-results/godot-tools/Godot_v4.7.2-stable_win64_console.exe --headless --path godot --script res://tests/receiver.gd
```

Both builders accept `-- --no-render`. `render_receiver.py` regenerates front/rear images from the saved master. `review_receiver_mcp.py` appends the recovered assembly to Blender through the local MCP client, preserving existing scenes. Normal import retains the committed lossless setting on the tiny keepsake kit; main receiver LODs and shadow meshes remain enabled.
