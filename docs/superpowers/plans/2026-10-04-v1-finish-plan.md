## Delivery order

Inspect and journal the baseline; test first-hour assumptions; implement bounded onboarding and three story performances; freeze runtime inputs; run the complete earned campaign with a living journal; resolve findings and run the affected regressions; package the verified result. Do not edit runtime sources during a source-stamped campaign run. If a defect stops a run, record it, preserve its logs/save, fix it and clearly label the new attempt. A resumed run is not an uninterrupted playthrough.

## Playthrough contract

The current automated actor stops after Wake. Extend it rather than reporting later prepared checkpoints as full progression. Input-driven movement, live hook trajectories, ordinary weapon fire, paid crafting and physically reached production controls are permissible automated actions. Programmatic aiming, known routes and scripted reading time must be disclosed. Preserve the user's saves in a separate campaign directory. Never silently supply resources, disable damage, skip enemies, change distance or accelerate time to claim normal pacing.

Use native rendered inspection and available Windows computer-use controls for menu/readability observations. The available UI API has discrete key presses rather than continuous held-key/mouselook controls; an authored native input actor is more reliable for a sustained action-game route. Neither form establishes an uncoached human's understanding or skill.

The [campaign journal](../../godot-port/v1-playthrough-journal-2026-10-04.md) is the running record. Each finding needs its evidence type, positive/negative observation, player impact, disposition and retest result. Do not turn source-reading hypotheses into claimed play observations.

## V1 stopping rule

The existing five-expedition campaign, optional missions, salvage/home loop and ending constitute V1's content scope. Finish when the earned route and ending work, essential directions are understood by fresh players, the authored story moments land, the downloadable build is reliable and no serious progression/save/collision/performance defects remain. Human reception and weaker-hardware acceptance require actual evidence and cannot be inferred from scripted checks. New regions, crafting trees and additional bosses belong to a later release.
